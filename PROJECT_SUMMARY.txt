HOW TO USE:
================================================================================

QUICK START (30 seconds):

1. Open Command Prompt/Terminal
2. Navigate to project folder
3. Run: python job_finder_advanced.py
4. Dashboard opens automatically
5. Search and click to apply!

DETAILED STEPS:

  Step 1: Run Advanced Version
    python job_finder_advanced.py

  Step 2: View Dashboard
    Automatically opens in browser
    (Or open Government_Jobs_Dashboard_Advanced.html)

  Step 3: Check Active Jobs
    Dashboard shows only active jobs (expired removed)
    Statistics show how many days to apply

  Step 4: Search Jobs
    Type: "SSC", "UPSC", "Bank", "Railway"

  Step 5: Filter Results
    Uncheck "GATE" to see non-GATE jobs
    Use Organization dropdown

  Step 6: View Details
    Click job card to expand
    Read all eligibility + steps

  Step 7: Apply
    Click "Official Website"
    Follow step-by-step guide
    Apply before deadline!

================================================================================
TROUBLESHOOTING:
================================================================================

Problem: "Python not found"
Solution: Install Python 3.7+, add to PATH

Problem: "jobs_database.json not found"
Solution: Ensure file is in same folder as script

Problem: Dashboard won't open
Solution: Manually double-click HTML file in folder

Problem: JSON format error
Solution: Use jsonlint.com to validate, check commas

Problem: Filters not working
Solution: Refresh browser (F5), try different browser

Problem: Expired jobs still showing
Solution: The script removes them automatically each run

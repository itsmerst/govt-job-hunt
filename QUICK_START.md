## 🎯 Using the Dashboard

### **Search Jobs**
- Type in search box: "SSC", "UPSC", "Bank", "Railway"
- Results update instantly

### **Filter GATE Jobs**
- Uncheck "Include GATE-Required Jobs" (default: off)
- Shows only non-GATE jobs

### **View Details**
- Click any job card
- See full eligibility, steps, documents
- Open official website link

### **Print Page**
- Click "Print Page" button
- Save as PDF
- Or use Ctrl+P / Cmd+P
